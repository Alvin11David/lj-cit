About This App

This is the CiT Student Grade Portal — a Phase 1 and 2 capstone project built during the CiT Frontend Engineering Track.

Built with Angular 21 and TypeScript. Week 13 added routing — multiple views without a full page reload. Week 14 connects the app to a live backend API with the Angular HttpClient, RxJS Observables, the async pipe, and a JWT interceptor.
